# S-104 – Mapowanie listy produktów do fdc_id

Epik: E1 – Baza żywności v1 (M1) | Kto: CC+P | Status: in-progress | Zależy od: S-101, S-102

## Cel
Każdy produkt z listy i jego wariant przypisać do rekordu USDA.

## Kontekst
Półautomat: fuzzy match nazw (po przetłumaczeniu) + ręczna weryfikacja kandydatów.

## Kryteria akceptacji
- [x] Narzędzie proponuje top-5 kandydatów z wynikiem dopasowania
  (`make map-products` → `data-pipeline/mapping/mapping_candidates.csv`, wynik 0–100)
- [x] Plik `mapping.csv`: produkt, wariant, fdc_id, status (auto/zweryfikowany/brak)
  (`data-pipeline/mapping/mapping.csv`; stan początkowy: 482 `auto`, 154 `brak` z 636 wariantów)
- [x] Produkty bez odpowiednika w USDA wypisane do uzupełnienia z Ciqual/Fineli
  (`docs/data/missing_in_usda.md`)
