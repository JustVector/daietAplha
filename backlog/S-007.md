# S-007 – Szkielet backendu FastAPI w Dockerze

Epik: E0 – Fundament repo (M0) | Kto: CC | Status: in-progress | Zależy od: S-003

## Cel
Postawić pusty backend REST API, z którym rozmawia baza, CLI i bot.

## Kontekst
FastAPI + Pydantic, połączenie z PostgreSQL, Alembic. Backend jako serwis w docker compose. Wszystkie interfejsy (CLI, bot Discord, przyszły WebApp) są wyłącznie klientami tego API.

## Kryteria akceptacji
- [x] Dockerfile backendu; `make up` startuje bazę i backend
- [x] `GET /health` sprawdza połączenie z bazą
- [x] Konfiguracja z `.env`, spójna obsługa błędów i logowanie
- [x] Dokumentacja OpenAPI pod `/docs`
- [ ] Test healthchecka w CI
